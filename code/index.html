What this is
An editor for reading, writing and trying code in eighteen languages. Highlighting is done here, in this tab, by a tokenizer you can read in src/highlight.js — there is no language server and nothing is sent anywhere.
Running
JavaScript runs in a sandboxed frame with no access to this page, and its console lands in Output. HTML renders as a preview. The other languages are for reading and writing here: running them needs a runtime this tab does not have.
